On the Spark itself there is a shorter way: ssh omega.local, cd into a project and run clone (or run it in your home folder to pick from ~/Development, or paste a git URL there to clone a new one). It runs inside tmux, so the agent keeps working if the connection drops; clone in the same folder picks it up again. make clone-command sets up the same command on a Mac, against this server.

    
Both commands run on any machine that can reach the Spark by the name chosen above. fable needs uv there and installs itself from this page; add --doctor to check the connection first. Claude Code needs the server to answer on /v1/messages; the first test checks that. The commands contain the API key.
